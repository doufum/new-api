# RightToken Icon Design

## 目标

为 `RightToken` 设计一枚可用于网站 favicon、品牌头像和站点图标的独立标识，同时延续当前站点已有的青蓝到粉紫渐变气质。

## 结论

最终采用 `C1` 方向，即“右向流转”的平衡版：

- 语义上强调 `Right + Token`，表现为 token 被路由、传递、放行的流动感。
- 造型上保留圆润和科技感的平衡，不做过度攻击性或过度卡通化处理。
- 视觉上沿用青蓝到粉紫的品牌渐变，降低与现有站点视觉体系的割裂感。

## 构成说明

- 外部弧线：代表 token 的轨道、通路和持续流转。
- 中部箭形：明确表达 “Right” 的右向动作与转发语义。
- 左侧节点：作为流转起点和 token 核心，使用浅色填充与深色描边，兼顾浅底和深底可见性。
- 背景：透明底，便于复用到 favicon、PNG、头像裁切和应用图标底板。

## 资产输出

- 主矢量文件：`web/default/public/righttoken-icon.svg`
- 常用位图导出：后续导出为 `32 / 64 / 128 / 256 / 512` 像素 PNG

## 约束说明

- 本次仅新增 `RightToken` 品牌资产，不替换项目内受保护的 `new-api` / `QuantumNous` 相关默认品牌信息。
- 设计遵循 KISS：只保留一层主弧线、一枚箭形、一枚节点，不引入多余装饰。
- 设计遵循 YAGNI：当前只交付最核心的品牌主图标，不额外扩展整套品牌系统。
